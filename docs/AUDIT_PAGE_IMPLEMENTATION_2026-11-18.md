## 一致性和安全边界

- 客户端证据只在当前标签页内存保存，切换身份/空间、退出、撤权时清理；迟到定位请求不得向新上下文写入数据。
- SSE 终态即使遇到随后失败或过期的 HTTP 请求仍保留。队列焦点/文本选择期间，先更新状态与禁用失效动作，离开交互后再移除旧行。
- 导出快照冻结的是选中记录的 ID 集合，不是长事务冻结所有可变字段。响应头 `X-Export-Snapshot: selected-identifiers` 明示这一点。中途权限收窄或选中记录消失会中止流，不静默交付伪完整结果。
- 先脱敏后截断，不解密/重放冻结载荷；耗时缺失不制造阶段证据。
- 原方案中的 CLS=0、40–50% 提速、60–70% CPU 降幅、首屏 10–12 行属于目标，不因功能实现就宣称完成性能认证。真实网络、线上数据规模、全平台 WCAG 与所有场景仍须独立测量。
