# MCP 面板统一优化 2026 10 06

## 范围与状态

本次在既有隐私修复和旧 ChatGPT 工作台退役改动之上，优化全部面板的共享组件及新增管理功能。未提交、推送、发布或部署；没有修改真实账号、凭据或线上权限。

覆盖清单包含 19 个顶层页面、8 个开发工具 tab、5 个 CLI 详情 tab，以及菜单、模态、表单、状态与附属页面，共 201 个检查项。截图数量不是功能验收数量，真实 SSO、扩展宿主、外部 MCP 与原生设备的最终接线仍需相应环境。

## 已落实的设计

- 我的账号、成员、身份管理使用共享网格、明确区块间距和紧凑空态；实体操作靠近对应内容，列表可以筛选并在刷新后保留筛选和焦点。
- 角色使用规则目录与单条编辑，保留所有规则控件的原 form 归属及逐规则权限语义；增删和字段修改不重建用户正在点击的目录按钮。
- Profile 分离连接身份、固定授权或当前角色政策、影响说明。不会自动选择 computer、全部项目或外部委派。
- OIDC 按连接、准入与群组、高级配置、安全检查分组；保留禁用和 closed 默认值、Issuer 只读及兼容提示。
- MCP 网关分为服务与账号、已发布工具、我的委派、调用记录。工具审核有搜索、已选计数、仅看已选与清空选择；筛选不改变选择，所有工具默认不选。
- 复杂编辑器和长只读详情在手机采用全页展示和单个返回入口，桌面保留分组宽布局。只读内容区可用键盘聚焦、翻页及浏览器返回，不误报未保存修改。浏览器 Back、按钮返回、Escape 共用未保存/提交中/未知结果保护；程序性成功关闭、登出及权限清理不受该提示阻断。
- 共享字段统一标签、必填提示与说明关联；菜单支持方向键/Home/End，受限页面与快速前往使用一致的角色过滤。
- Agent、VPS、项目、工作流与产物复杂表单沿用新的承载和字段规范；浏览器扩展 popup/idle 与保留的改动审阅卡统一阅读节奏、颜色与触控尺寸。
- 拒绝重试、延迟回包、旧弹层保存和角色变更均保留原有安全边界。

## 额外修复的恢复与错误状态

新增回归复现了同账号会话失效期间撤销项目 read 后，工作台旧源码/输出仍残留于恢复缓存的情况。现在在恢复私有 DOM 前重新读取项目权限和映射；CLI 缓存另经服务端现有 write/execute 边界检查。权限明确撤销时清除对应源码、输出、附件与回执；网络失败时继续隔离悬挂草稿，不显示或重发。

为此新增只读 GET /api/native/access?project=...，只调用既有 NativeService.project 授权路径，不启动 Agent 操作，不放宽权限，也不创建新凭据。

网关凭据提交结果不明时锁住重复提交并清除输入中的秘密值。空凭据不会被自动当作改为无认证；移除旧凭据必须明确勾选。纯本地校验失败不锁成网络未知状态。
