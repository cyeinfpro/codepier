# 常见问题与排查

## 新增项目后为什么还不可用？

先核对 Agent 在线、项目映射目录有效、客户端范围包含该项目。已经建立的 OAuth/PAT 可在“MCP 接入 → 调整项目范围”选择全部现有及未来项目，原令牌保留。系统设置的默认值只预选新授权；只有明确确认应用到已有 OAuth 连接才会更新它们。关闭默认值不会撤销旧权限。[接入说明](CHATGPT.md)。

## 面板允许执行，Agent 仍提示未开启？

客户端 execute、项目执行设置和 Agent 本机能力分别检查。新安装弹窗可勾选 Shell 和目录任务，普通升级不改变旧配置。已有节点从系统设置查看本机启用命令，在原安装账号、原解释器和原配置下执行；不要重新初始化或另建节点。完整 Shell 使用系统用户权限，不是目录沙箱。只需要具名任务时，不必开启完整 Shell。[安装说明](AGENT_INSTALL.md)。

## 更新完成为什么暂时没有自动刷新？

新版页面等待目标版本真正就绪；有未保存输入或会话草稿时暂停刷新，处理后继续。失败、回滚和只完成下载不会触发刷新。首次从旧版升级时，旧标签页尚无新逻辑，需要刷新一次。面板更新只替换服务器端 Hub、网页及可下载 Agent 文件，不会强制重启所有节点。[面板更新](PANEL_UPDATE.md)。

## 节点离线、pending 或 unknown 应怎么办？

先记录 operation_id。用 operations_wait/get 查询同一操作，响应丢失按原幂等键查找。queued 可能等待设备连接；running 不保证外部业务已完成；unknown 或 needs_review 必须核实实际效果。取消传输不能保证远端 Shell、SSH 或文件副作用回滚，不用新键盲目重复。

检查节点自身日志、Hub 可达性和设备是否启用。能在面板读取文件后再排查 MCP 连接，避免混淆两段网络。不要删除 journal、数据库或实例锁来伪造“恢复”。

## 已安装为何不能直接重装或卸载？

修复升级要求同一设备身份、可验证的受管目录和服务，保留配置与配对。未知安装、目录冲突、活动任务或服务停止失败会拒绝维护。卸载会删除安装目录内的配置、状态和密钥，但不删除外部项目和 Hub 记录；先备份需要保留的状态。在目标电脑自己的终端操作，不让正在维护的 Agent 远程卸载自己。[生命周期](AGENT_LIFECYCLE.md)。

## Windows 关闭终端后不在线？

用原用户的 codepier-agent.ps1 status/start 检查受管任务及日志。首次注册开机任务需要 UAC，但 Agent 不是长期以管理员权限运行。S4U 后台任务没有交互桌面、映射盘或完整集成网络凭据；桌面控制需另行配置。旧安装需要一次本机修复升级才能获得新版服务配置。自动化恢复测试不等于已经实测重启后未登录的生产机器。

## 模型列表加载失败、刷新也没响应？

先核对项目所属节点、所选 CLI 是否安装并完成其原生登录。目录查询是只读请求，失败可以重新刷新，不应创建会话或发送消息。先前成功目录会保留，迟到结果不能覆盖新会话。CodePier 不替换个人 CLI 账号和配置，也不通过发起付费模型请求来诊断元数据。回到目标草稿后核对 CLI、模型和工作目录。[会话说明](CLI_SESSIONS.md)。

## 浏览器扩展在线但原生宿主未连接？

核对当前用户的安装回执、宿主注册、扩展 ID、独立浏览器档案和本机日志。macOS 的 Downloads 等受保护目录可能阻止浏览器启动宿主；受管宿主应使用自己的安装文件，测试使用系统临时目录。不要修改系统隐私数据库、授予整盘访问或关掉安全检查来绕过。浏览器档案和站点权限与普通项目文件权限独立。

## 公网 HTTP 可以直接连 ChatGPT 吗？

CodePier 的 HTTP API 可用于受控网络，但不能据此保证外部平台接受公网明文入口。采用可信 HTTPS + OAuth 或官方 Tunnel。检查公开基地址、同源/CSRF、回调地址和工作区权限；不要把客户端401/403通过关闭认证解决。[接入说明](CHATGPT.md)。

## 工具版本不兼容是否会重复执行旧操作？

不兼容的新调用会明确要求核对 Hub/Agent 版本。排队请求保留原工具语义版本，已投递请求仍按旧编号恢复，不自动转换成新调用。目录摘要不同也可能只是新增工具；是否可调用以该工具版本和最低版本检查为准。先更新兼容组件，再核对旧操作真实状态。

## 丢失 master.key 或轮换中断怎么办？

不能从数据库恢复丢失的解密密钥。数据库与对应 master.key、master.keys.json 必须一起备份；轮换期间还要保留 .rekey 记录和备份。离线维护使用 rekey --resume 恢复原事务，不删除进度、不把旧数据库覆盖到新业务数据上。[安全备份与轮换](../SECURITY.md)。

## 测试通过为什么仍需要目标平台验收？

本地测试可以使用真实 Hub/Agent/浏览器和确定性 CLI 替身，不代表真实付费模型、Windows/Linux 桌面、Docker 数据卷迁移或实际账号接入已验证。分片成功也不是全套成功；必须合并所有分片并核对测试 ID、源码摘要、失败、跳过和退出码。[开发与验证](DEVELOPMENT.md)。
