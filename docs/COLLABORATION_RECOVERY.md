# 协作恢复、任务预算与通道边界

本指南说明 1.27 的仓库实现及部署边界。代码和本地回归不等于外部宿主、微信账号或生产设备已经接入；发布不会自动启用这些能力。

## 原工作恢复

恢复沿用原连接、房主批准、项目、工作项、尝试及 fencing token。操作回执、节点联络、任务输出、消费者心跳和有意义进展分别记录；查询状态不会制造新的执行或活性证据。结果未知时先查原回执，不重新运行命令生成结果。

宿主参数保留对象式兼容包络，实际动作仍由服务端精确校验。旧 CPJ 通知模式、旧消息长度和旧结果接口保留原语义，不因新工具目录自动扩大权限。

持久发件箱提供参考适配器：发送前保存原意图、请求键和内容摘要，丢失回执后核对同一请求。实际宿主必须在自己的持久存储集成并证明恢复；仓库包含适配器不证明任何外部宿主已经采用。

## 有界长命令与结果

只有协商支持的新 Agent 和房主显式选择的正数预算，才使用独立的命令硬期限。消费者租约控制开始，续心跳不延长已经批准的执行期限。旧预算为零和不支持新协议的节点保持原规则，不静默降级。

版本化结果允许明确预声明的只读探索失败被同一次尝试中的后续成功读取补救，保留失败历史和替代关系；必要步骤失败、写入副作用或不确定结果不能这样隐藏。过期结果归档仅封存当前仍可读取的原尝试证据，不复活租约或降低 fence。

## 房间范围与附件

范围绑定服务器保存的既有 grant，并与当前 Profile、Role、逐项目能力、映射、目标环境及期限取交集。撤销或过期不退回更宽旧授权；排队交付前再次核验。

该范围不是操作系统文件、进程或网络沙箱。未验证严格隔离时不能声称具备沙箱；执行需符合已明确接受的 Agent 账号权限边界。

长回复使用显式版本2。附件仅引用房主批准的已有分享记录，绑定原消息、版本、身份、联系人、范围和期限；不接纳任意路径或外部下载链接。续传读取原产物和分段，不重跑生成任务。读取、缓存与外发各自重新检查当前授权。

## 默认关闭的微信通道

CODEPIER_WEIXIN_ENABLED 默认 false。部署负责人明确启用后，房主仍须登记已有授权机器人、确认接入方向、完成配对挑战并核对实际联系人。凭据配置及真实账号操作需要独立授权，源码发布不执行这些动作。

外部消息保留外部通道身份，不能冒充房主或直接批准执行。入站游标、去重和规范消息原子保存；账号或绑定变化后旧响应不能提交。外发仅使用批准的 HTTPS 目标，核验 HTTP 与业务返回值。

发送开始后的超时、断线或崩溃可能已经产生副作用，因此保持 unknown，不自动换键重发。人工确认只代表人工证据，不等于平台已送达或已读。一个未知通道保持自身顺序，不能阻塞其他正常通道。

真实微信账号收发、媒体往返、服务端上下文期限和异常回执需在另行批准的测试账号中验证；固定协议、合成事务与浏览器测试不能替代这项验收。

## 验证与发布

完整发布必须以最终同一提交的回归和归档证明为准，不累加早期通过数。真实 10/30 分钟静默命令验收用 CODEPIER_LONG_BUDGET_TEST=1 显式执行，单模块预算至少 2400 秒；不是快进时钟模拟。兼容 SDK 使用独立的 MCP_COMPAT_PYTHON。

本地可使用测试专用 CODEPIER_TEST_STACK_PYTHON 为真实 Hub/Agent 选择已有完整解释器，浏览器驱动保持在自己的依赖环境；不拼接 site-packages。未设置时沿用默认解释器。跨平台、生产部署和外部宿主验收结果须分别报告。
