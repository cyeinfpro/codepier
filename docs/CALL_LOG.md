# 工具调用流水

入口：面板 → **操作审计 → 工具执行**。全部事件仍保留在相邻标签页。

## 阅读一次调用

每条记录默认折叠，显示工具名与中文类型、路径或命令摘要、项目与设备、调用来源、时间、操作编号、执行状态和总历时。读取、写入、编辑、命令使用不同类型标识；状态同时有文字，不只依赖颜色。

点击记录或聚焦后按 Enter / 空格展开。详情按需读取已保存的参数摘要、任务输出、返回结果和执行链路，不重新调用原工具。长内容各自折叠，可以复制已脱敏内容；超过展示预算会明确提示截断。任务输出展示保存内容的尾部，而不是把旧输出冒充最新输出。

总历时是 Hub 创建至更新/当前时刻的跨度。执行前等待使用 Hub 观测到开始执行的时间；实际执行使用同一次 Agent 处理的单调计时差。阶段缺失、旧版 Agent、历史被裁剪时显示“未记录”，不从 HTTP 返回时间猜测执行耗时。HTTP 200 不等于命令成功；失败任务保留失败状态和退出码。

## 筛选、实时更新与导出

支持项目、工具、来源和状态组合筛选，以及路径、命令摘要、调用者和操作编号搜索。搜索范围是数据库中已经保存的摘要，不包含被省略的文件正文或被截断的命令尾部。

页面订阅已有操作事件并以约 5 秒间隔补偿同步。可以暂停、恢复或手动刷新。展开中的记录、输出滚动位置和文本选择不会因为新记录插入而被整页替换；阅读时会出现“列表有更新，显示最新”按钮。历史页使用创建时间和操作编号组成的稳定游标，不因新调用插入造成偏移分页重复。

“导出本页调用”输出当前页的已脱敏 JSON 摘要，最多 40 项，不表示导出全部历史。需要事件 CSV 时切换到“全部事件”使用原有导出入口；该入口仍遵循原有筛选和每次最多 10,000 条的限制。

## 隐私与权限

接口只允许已登录的面板管理员读取；MCP Bearer 凭据不会自动获得面板日志权限。响应禁止缓存。详情仅保留在当前标签页内存，退出或登录主体变化时清除，迟到响应不会恢复上一账号的数据。

不为详细日志另存完整请求体，不解密持久队列 payload 展示参数，不额外保存文件正文。已有参数摘要继续以字符数替代正文；新增调用保存编辑次数和原始命令字符数。环境变量值、可识别的密码、令牌、授权请求头、Cookie、URL 内凭据和私钥默认脱敏。自动脱敏不能识别所有无标签的秘密值，分享导出或输出前仍应复查。

列表不加载 result、output 或加密 payload。详情采用独立、有限预算的查询；数据库访问沿用 Hub worker，不在 ASGI 事件循环中直接执行 SQLite 查询。读取执行链路不会产生新的工具调用审计，避免日志轮询不断制造日志。

## 开发与验证

模块：`hub/call_log.py`、`shared/audit_redaction.py`、`web/call-log.js`、`web/call-log.css`。

修改面板脚本或样式后，重新生成静态资源清单：

```sh
python scripts/build_web_assets.py
python scripts/build_web_assets.py --check
python -m pytest -q tests/test_call_log.py tests/test_call_log_api.py tests/test_call_log_browser.py tests/test_call_log_fullstack.py
```

测试包含脱敏、旧记录兼容、游标分页、授权、截断、输出尾部、网络错误、复制、导出、实时更新、登录生命周期，以及真实 loopback Hub / Agent / Chromium 联调。源码修改不等于已更新运行中的 Hub；按项目现有发布和面板更新流程部署后生效，无需重新配对 Agent 或重新创建 MCP 授权。
