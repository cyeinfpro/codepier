# CodePier 全站体验统一（2026-10-12）

## 目的与范围

本轮在既有设计系统和依赖上落实全站 UI / UX / 动效一致性。保留 CodePier 黄色品牌与语义状态色；采用清晰层级、稳定布局、克制反馈与可访问性原则。范围为登录入口、20 个主路由、共享导航/控件/面板/加载错误反馈。业务权限、独立授权与审批流程不在本轮变更范围内。

基线：功能分支 commit `0fd57e9694b847c30572590294e5e708909e6d90`。最终整合需要同时保留后续 Windows 安装补丁及协作生态业务补丁。这里的截图与浏览器验收均来自隔离本地 Hub + Agent 生成数据，不表示线上已部署。

## 官方设计依据

2026-10-12 通过云浏览器实际读取 Apple Developer 原文：

- [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)，页面标记更新 2026-09-09：按相对重要性组织内容，用对齐、间距和分组表达关系；布局适应窗口与文字变化，保留功能可达性。
- [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：动效须有明确用途，反馈简短、可打断；不以动画作为重要信息的唯一表达；避免让频繁操作等待动画。
- [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：支持键盘、较大文字、合适触控尺寸、浅深色对比度与减少动态效果；不能只靠颜色传达状态。

这些原则用于 Web 产品的结构与交互判断，不复制 Apple 商标、产品屏幕或将原生平台单位等同于 Web CSS 单位。

## 统一契约

| 项目 | 实现 |
| --- | --- |
| 字体 | 系统字体栈，正文 14px、辅助 13px、次要 12px、输入 16px |
| 间距 | 沿用 4 / 8 / 12 / 16 / 20 / 24 / 32px 刻度 |
| 控件 | 常规 40px、紧凑 36px；移动主控件至少 44px |
| 圆角 | 控件 12px、桌面面板 20px、移动面板 18px |
| 层级 | 中性内容表面、较轻实体封面、稳定标题与操作位置；黄色保留主要行动 |
| 导航 | 232px 桌面边栏、移动抽屉与底部导航；本地页面筛选、无结果提示、Escape 清除与焦点返回 |
| 反馈 | 保留稳定状态文本，页面加载携带目的地，错误携带页面标题/原因/重新加载入口 |
| 动效 | 控件 120ms、页面/弹窗 180ms，页面与弹窗仅淡入；交互不会等待动画完成 |
| 可访问性 | 3px 焦点环、浅深色语义对比、增加对比度、强制颜色、减少动态效果 |

所有语义 `--ui-*` 状态色保留。新增 `web/experience.css` 是共享体验层，加载在业务样式之后；不重写协作 cc-* 状态/恢复逻辑。所有导航筛选仍调用既有 `CodePierIdentity.canNavigate`。

所有 20 主路由分别在 Chromium 与 WebKit 的 360 / 390 / 1440 CSS px 视口验收（120 个路由-视口-引擎组合）。额外验收包含导航搜索/Tab/Enter/Escape、移动焦点陷阱与恢复、无权页面隐藏、请求失败/重试/过期回包、light/dark × 两引擎、减少动态效果、增加对比度与 720 CSS px 重排（1440px 显示的 200% 缩放布局宽度）。后者是等效布局宽度检查，并非操作系统文字放大或真实浏览器缩放模拟。

## 可量化变化

- 390 与 360 视口，20 路由初始渲染中检测到的高度不足 40px 按钮，从每个视口 11 个降为 0。涉及总览入口、设置分类、CLI 文字按钮与失败重载。测试同时针对关键触控控件验证 44px。
- 页面/弹窗标准动效 220 → 180ms，控件反馈 140 → 120ms；减少动态效果时无动画和过渡。没有添加循环装饰动画或全站模糊效果。
- 60 张基线和 60 张修改后初始视口截图均为 0 个页面级横向溢出、0 个 JS pageerror。
- 本地受控导航加固定 260ms 稳定等待的中位数：桌面 283 → 282.5ms，390 为 276.5 → 286ms，360 为 275.5 → 277ms。该测量仅用于发现明显回退，包含固定等待、机器负载与截图环境差异；不能宣称线上性能提升。
- 导航新增本地筛选，只遍历现有 20 个页面按钮，无网络请求、存储或新依赖。搜索“设置中心”将列表收窄至一个可见结果，可直接 Tab / Enter 前往。
