- 667×375 协作室横屏去掉重复顶栏，保留底部导航和完整消息；320×568 竖屏压缩无效留白，保持完整短消息与 44px 触摸控件。修复 WebKit 原生选择框忽略 min-height 的问题。
- 增加只读审计、默认 dry-run 的 token codemod、精确回退白名单、漂移护栏与维护指南。

## 指标与方案修正

原方案同时要求 tokens.css 外十六进制颜色不超过 20，以及保留会话/授权样式独立加载的精确十六进制回退。这两项不能同时成立，仅现有会话契约就固定了 36 项回退。

因此审计同时公开原始数量和兼容回退数量，而非隐去原始指标。白名单逐条绑定文件、条件、选择器、属性、值和次数，仅接受 chat/computer 的必要 var() 回退；其值已对照共享 token。新选择器、值变化或额外一次出现均不自动豁免。

token 与带同值回退的 token 具有不同源码表达式，但属于同一视觉尺度。原始表达式和语义尺度均单独报告并设置只降不升基线。原 codemod 的 8–10px→11px 也已修正为至少 12px，避免违反中文可读性要求。

| 指标 | 原方案基线 | 实施后 |
|---|---:|---:|
| tokens 外原始十六进制颜色 | 236 | 152 |
| 精确独立加载回退颜色 | 未单列 | 149 |
| 其余原始颜色 | 未单列 | 3 |
| !important | 59 | 15 |
| 原始 z-index 声明 | 31 | 10，全部为组件内 1–5 |
| 小于 11px 字号声明 | 112 | 0 |
| 小于 12px 字号声明 | 未单列 | 0 |
| 字号表达式 | 53 | 原始 17 / 语义 9 |
| 圆角表达式 | 45 | 原始 22 / 语义 8 |
| 字重种类 | 10 | 4 |
| 原生 confirm 调用 | 41 | 12 |
| 原生 showModal 调用点 | 4 | 1 个共享入口 |

3 处非回退颜色为 QR 白底及远程屏幕画布前景/背景；15 处 !important 留给 hidden、reduced-motion 等基础设施。12 处同步确认主要为导航、退出、脏表单和发布状态守卫，没有机械改为 Promise；继续迁移须先重构相应状态机。
