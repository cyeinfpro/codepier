## 审查中新增修复

1. **P1：原生同步后台任务未参与关闭。** `NativeService.submit()` 新建独立任务后，Runtime 的连接失效/关闭未取消和等待这些任务。慢 ACK 可使关闭返回后仍有任务使用 Store。现在断开原连接时取消其队列，关闭时停止新提交并等待在途事务取消完成。回归以实际持久化、阻塞 ACK 和第二个排队包复现；修复前失败，修复后不再写入第二包。
2. **P2：微信绑定的展示成员与执行成员不一致。** 显示层会回退到可用主责成员，绑定层仍读取流程中已暂停成员。现在采用同一成员解析，并把展示成员 ID 放入下一请求，显式提交仍校验房间归属和状态。回归在创建流程后暂停原成员、切换主责，验证实际绑定与展示一致。
3. **P2：启动未完成时离开页面报 ReferenceError。** 新协作界面的 pagehide 和更新面板的 pageshow 在 app.js 声明 S 之前读取它。现在先检查初始化状态。增加暂缓真实 app.js 响应后触发生命周期及真实导航的 Chromium/WebKit 用例；不伪造应用状态。
