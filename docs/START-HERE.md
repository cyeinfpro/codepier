# 开始使用 CodePier

新安装按“Hub → Agent → 项目 → MCP 客户端”验证。已有安装不要重新初始化、重新建立节点或删除数据库；先备份数据库及对应密钥，阅读 [Agent 升级](AGENT_INSTALL.md) 和 [命名迁移](CODEPIER-MIGRATION.md)。

## 部署 Hub

在服务器准备 Docker Engine、Compose 和用于安装器的 Python 3.9+，在完整源码目录执行 `bash install.sh`。配置实际监听地址和管理员账号；公网访问使用 HTTPS，只信任实际反向代理的地址。完整命令和 HTTPS 示例见 [README](../README.md)。

## 接入 Agent

在面板“设备节点 → 接入电脑”选择系统，填写节点可访问的 Hub 地址及已经存在的绝对授权目录，将生成的命令复制到目标电脑的本机终端。一次性票据和配对配置不能公开分享。等待节点上线，再在面板创建具体项目映射。

新安装可以选择开启 Shell 和目录任务；完整 Shell 使用安装用户的系统权限，不是项目目录沙箱。普通升级保留旧的权限选择，不会静默打开执行或桌面能力。[详细安装、升级与卸载](AGENT_INSTALL.md)。

## 先验证文件，再连接 MCP

先在面板工作台读取授权项目中一个无敏感信息的小文件。读文件成功后，再按 [ChatGPT 接入](CHATGPT.md) 配置公开 HTTPS + OAuth 或官方 Tunnel。工具发现与调用按实际返回目录验证，不依赖文档中易过期的工具数量。

新增项目经常需要重新授权时，检查连接是否明确选择“全部现有及未来新增项目”；限定项目连接可在“MCP 接入”调整范围，不必更换令牌。遇到等待中的操作，保留原编号并查询结果，不重复发起写入。

常见错误、离线恢复和升级排查见 [FAQ](FAQ.md)。上线前核对 [安全说明](../SECURITY.md)，开发和测试入口见 [开发与验证](DEVELOPMENT.md)。示例路径、测试数据和截图不代表用户的生产配置。
