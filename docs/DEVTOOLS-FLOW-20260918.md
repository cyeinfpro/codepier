# CodePier · 开发工具工作流

本次为源码更新；不代表现用 Hub、Agent、浏览器扩展或客户端缓存已更新。没有重启服务、启用本机语言服务、扩大网站权限或启动真实模型会话。实际回归结果应查看对应版本的验证记录；历史本机证据不随公开源码分发。发布门槛见 [发布清单](RELEASING.md)。

## 从当前工作进入

原「开发能力」改为「开发工具」，默认页为「开始工作」。先确认顶部项目、设备和操作目录；读取、验收与网页租约都沿用这个范围。原项目目录和隔离目录不会自动混用。

CLI 会话的「更多操作」提供当前项目开发工具、测试与验收、任务衔接。工作台可直接进入测试验收；编辑器的代码导航会带入文件及当前光标位置。任务详情可以进入该任务的交接；设备管理按项目提供配置引导。

从这些入口离开会话不停止模型进程。进入 CLI 草稿也不启动模型；只有你检查内容并发送后才开始执行。开发工具不猜测某项任务对应哪条历史 CLI 会话。

## 开始工作与配置状态

开始页提供检查修改、任务衔接、网页验证和代码导航的场景入口。就绪检查和任务列表独立读取；一个区块失败不会遮住其他区块，可在原位重新读取。

「已就绪」只表示本次凭据和目标设备满足调用条件，不等于某项任务测试通过。语言服务程序存在、协议查询完成、浏览器连接、站点授权和实际操作成功分别核对。磁盘与运行进程源码不同会提示先检查设备维护状态，不会自动重启。

配置引导提供目标设备、步骤、下载和配置片段。它不替换完整 Agent 配置，也不自动安装程序、添加授权、应用配置或重启服务。安装、预览、明确应用、正常重启和重新检查是独立阶段。平台安装参数与卸载边界仍见 [集成安装说明](INTEGRATIONS-20260917.md)。

## 测试验收

填写验收名称、命令和最长运行秒数。示例按钮只填写命令，不运行。执行前确认项目、设备、目录、命令与时限。命令仍使用 Agent 系统账号权限，不是操作系统沙箱。

执行结果先显示状态、退出码和实际输出，技术回执折叠保留。历史列表不把旧的通过当作当前版本通过；打开详情会重新核对源码，并读取原执行操作的输出，而不是重新运行测试。

只有当前状态通过、已取得原输出且你勾选人工复核后，才能接受验收。接受或拒绝可填写备注，提交时后端再次检查。命令通过、人工接受、任务完成、合并和部署不是同一件事。

## 原操作恢复

在同一页面会话中，提交后的操作编号不因切换开发工具分类或项目丢失。仍在执行或回执丢失时，上方显示「待确认的操作」，先查询原结果。换参数重新提交同类操作会被阻止，避免把不确定结果变成重复执行。

没有收到操作编号时，使用原幂等键查找服务端记录。只有原参数仍在当前页面内存中，且已先查找原记录，才提供显式「重试同一请求」。不会自动重放结果不明的输入。

同一浏览器标签页的刷新恢复只保存操作编号、幂等键、项目、工作目录和阶段等查询元数据，不保存命令、网页输入、配置片段、认证信息或输出。刷新恢复最多保留最近 40 个待确认请求；完整原操作仍可在操作审计中查询。刷新后的记录仅能查询，不恢复可执行参数。已确认请求从页面内存移除；退出登录时清除工具页草稿、请求内存及这些元数据。这不是跨浏览器或关闭浏览器标签页后的任务队列。

离开页面会停止页面读取与轮询，不取消已经提交到服务端的命令。需要停止时先查看原操作及相应停止入口。

## 任务衔接

交接页先展示原目标、断点、完成记录和待办。项目近期结果不明的操作单独标注；这些是项目范围的线索，不代表全部属于该任务。

可以复制交接说明、打开完整任务或带到 CLI 草稿。已有草稿会要求核对替换，不自动发送。项目映射已经变化或任务位于不兼容隔离目录时，不会将旧任务直接投递到原目录。历史记录不是新的权限授权，继续工作前应读取当前代码及原回执。

## 代码导航与隔离目录

查询表单按动作只显示相关输入。项目符号查询要求语言与关键词；定位类查询使用文件、行、列。位置是从一开始的 Unicode 字符坐标，打开结果时转换为编辑器位置。

语言服务分析已保存文件，不分析浏览器内尚未保存的草稿。打开同一文件时保留现有草稿；改换文件或目录前需明确确认丢弃未保存内容。源码变化、部分结果及未收到新诊断不会伪装为当前源码全覆盖证明。

隔离目录使用原有 Git worktree 后端。需要已有提交及合法可写父目录，不初始化 Git、不复制原项目未提交修改、不自动合并、不强制移除脏目录。编辑与验收继续绑定该目录。原生 CLI 目前不接受受管隔离目录编号，因此该范围下不提供直接进入原目录会话的捷径。

## 网页验证与接入控制

网页验证先检查本机启用、连接、档案、准确站点和空闲标签页。只使用本机扩展已准备的后台页，不创建或激活用户窗口。页面内容作为不可信数据展示，不授予任何提交、删除、购买或发送权限。

先观察页面，再明确确认一步动作。一次动作消耗一次观察，之后必须重新观察；回执只表示动作派发情况，不等于网站业务成功。释放页面会区分租约撤销与标签页清理确认。

项目级暂停、恢复和紧急停止收进运行诊断的折叠区。必须输入完整项目名称确认；默认不包含原生 Pi/Codex 会话。紧急停止只处理有归属证据的任务，不关闭 Agent，不影响其他项目。进入隔离目录时不能误用项目级控制。

## 可访问性与显示

支持键盘方向键、Home / End 切换页签，保持焦点与当前页签的可访问关联。窄屏按列折叠，表格局部滚动，配置与回执长文本换行；遵循原浅色、深色和减少动态效果设置。具体浏览器、尺寸、截图以及未验证范围以本次验收记录为准。
