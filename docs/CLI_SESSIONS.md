# CLI 全局会话与操作流程

本文描述当前源码的会话边界；历史验收保留在本地归档，不能充当现用服务或当前测试结果。

## 浏览全部会话

侧栏默认显示所有当前有权限访问的项目的已同步聊天记录，按最近活动时间排序。项目归属作为每行的文字标签保留，CLI 类型和运行状态独立显示；完整标题、节点、目录及时间可从行的提示中查看。离线节点仍能读取已经同步的历史，不把节点离线显示成任务正常在线。

历史项目筛选、状态筛选、关键词与当前执行项目相互独立。筛选不会切换当前聊天，不会清空草稿，不会改变消息的发送目标。跨项目打开历史会使用该记录的 project_id 和工作目录；Windows 路径会归一化为项目相对目录。列表每页 50 条，支持超过原先 1,000 条偏移上限的历史；删除末页最后一条时回到有效页，而不是滞留空白页。

搜索覆盖会话标题、项目、节点、目录、CLI 及已同步的公开消息文本。中文 UTF-8、JSON 事件跨分块和增量文本边界均有回归。原生配置、审批详情等不是搜索侧信道。每次查询都会重新核对当前项目映射和权限；全局浏览并不扩大授权。搜索只覆盖已同步内容，不声称搜索未同步的本机历史。

列表有独立加载、空结果、失败、保留上次结果、重试与清除筛选状态。可见页面每 15 秒更新列表和节点状态；离开页面停止定时更新。回到页面或网络恢复时重新检查，不自动发送草稿。

## 新对话

流程：新对话 → 搜索/选择项目 → 确认草稿区的工作目标 → 选择 Pi/Codex/Claude、模型、思考强度与子目录 → 输入消息 → 首条消息发送时创建会话。

项目选择弹窗展示名称、节点、目录和权限/在线状态，支持搜索、方向键、Enter、Escape、关闭按钮和管理项目入口。打开或取消弹窗不会停止或替换原会话；选择项目只是进入对应草稿，不调用模型。离线项目可以准备草稿，发送前检查连接；无执行权限的项目不可作为执行目标。

草稿按项目、CLI 与目录保留在当前登录页面的内存中；回到已有草稿时明确提示。未承诺刷新整个页面后仍保留未发送草稿，也不把提示词、附件或认证信息写入浏览器持久存储。已发送历史由现有同步机制保存。模板、消息编辑、撤回文本覆盖现有草稿之前需要确认。

## 模型目录和设置恢复

模型目录使用独立只读请求，取消普通操作的多轮网络退避；HTTP 请求限时 18 秒，整体查询兜底限时 22 秒。失败、超时、取消、退出登录都会释放 pending，不永久缓存失败 Promise。主动刷新替代旧的普通查询；重复点击同一次刷新合并，不反复启动探测。

模型能力按节点/CLI 复用，项目默认值与指令按项目映射和工作目录隔离。Agent 将成功目录以私有文件持久化，正常查询复用 24 小时，重启后仍可读取；手动刷新立即重新探测。缓存按项目、节点、CLI、工作目录、模型和运行环境隔离。模型查询失败时回退到同一缓存键的最后成功结果并附带过期标记；首次读取失败且无缓存仍报错，指令查询不使用失败回退。失败保留最后成功取得的模型目录；旧请求不能覆盖更新的刷新结果或新登录会话。最新目录不再被旧会话的模型列表遮蔽。原生已确认的实际模型和思考强度仍是会话设置的依据，不把目录查询当成设置成功。

Hub 的目录查询超时返回专门的只读错误说明，不再提示用户拿输入回执确认目录。重试目录不创建会话、不发送消息、不更改个人全局配置。

设置控制与目录刷新分别管理回执。设置失败晚到时记录到原会话，不污染其他项目；回到原会话能看到失败和重试入口。结果不确定时复用原回执；明确失败后才能发起新的设置。思考强度主动切回默认时保留空字符串的明确选择，不被旧值覆盖。设置确认后自动恢复发送按钮，无需再输入一个字符。

## 消息、附件、控制与阅读

附件上传绑定发起上传的草稿、项目与登录会话。切换聊天不会遗失上传状态；多文件先登记到原草稿再逐个上传。移除和退出登录停止后续上传步骤，上传进度异常可重试；正在确认发送的附件不可移除。附件库的上传、刷新、附到消息、删除都有相应状态和确认，不影响用户项目中的原文件。

撤回只有拿到完成回执才移出队列；撤回并编辑不会覆盖另一个项目或用户后来输入的草稿。多个待取回文本依次保留，通过“取回已撤回消息”恢复。设置队列不提供伪装成文本消息的编辑入口。

新会话不显示可执行的停止、恢复、导出、删除操作；运行中、已停止、正在恢复、节点离线等状态分别决定按钮可用性和说明。恢复重复点击有防重，连续多次恢复使用新的会话 ID。删除仅作用于网页记录，不删除原生历史或项目文件；正在运行的会话必须先停止。压缩上下文前说明可能产生模型费用并再次确认。

本地界面指令（如 /new、/model、/stats）不受节点离线限制；它们不代替原生执行命令。中文输入法确认键不会误发送。消息查找、选区、阅读位置、工具折叠、上下文统计分别属于当前会话。增量回复不会把正在阅读历史的人强拉到底部。固定改动审阅使用原快照；切换会话时在途读取仍归原审阅节点，不丢掉唯一的分页入口。

## 键盘、弹层与窄屏

项目、模型与快捷操作都支持从搜索框或已聚焦选项使用方向键，并确保 Enter 操作与高亮一致。关闭/刷新按钮上的 Enter 不会误选模型或项目。弹窗关闭后返回合理的焦点；手机侧栏隐藏时不可被 Tab 聚焦。菜单、详情、模型浮层、工作目录和历史抽屉均有退出路径。

桌面、平板、320px 手机与横屏短窗口使用同一套中性浅/深色主题。侧栏避免装饰箭头挤占项目标签和标题；历史滚动区保留空间，顶部入口与底部控制不因短屏互相挤出视口。输入区、浮层与触屏控件保持在可视区域。具体尺寸、浏览器与按钮覆盖见最终验收，不将模拟视口称为实体设备验收。

## 验证与边界

测试使用真实 Chromium/WebKit 渲染，以及临时 Hub/Agent/加密传输/SSE；上游 CLI 采用确定性测试进程，不调用生产付费模型。全仓回归通过完整收集、保持模块内顺序的独立 pytest 分组执行；核对完整收集的测试 ID、各组退出码与 XML，并记录交付源码 SHA；超时或失败的尝试单独保留，不用简单相加重复的通过数。

没有把真实 Safari 应用、实体 iPhone、真实 Windows/Linux 桌面、用户生产模型上游或现网发布标成已验收。提交、推送、发布和部署必须分别核对真实记录；`RELEASE.json` 不是本地工作树测试通过的证明。
