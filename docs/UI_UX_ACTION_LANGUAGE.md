# UI 动作与状态词典

此表适用于面板、当前房间、原生会话、扩展、安装器及用户文档。诊断码、协议字段和可复制的原操作编号保持原样。UI 简化不得改变权限、幂等或恢复合同。

| 实际动作/证据 | 推荐文字 | 不能暗示 |
| --- | --- | --- |
| 按原 operation_id 查询终态或输出 | 查看原结果、继续核实 | 新建执行、改参数或换幂等键 |
| 原任务仍在进行，仅停止客户端轮询 | 停止等待 | 取消工作、撤回已派发效果 |
| 请求服务器取消原任务 | 取消执行；显示取消后果 | 已撤销写入、已完成清理 |
| 传输断开，恢复同一会话连接 | 重新连接 | 重新执行原命令 |
| 明确失败，允许创建独立的新执行 | 重新执行；显示目标与范围 | 只读查询、无副作用 |
| 配置写入已确认，但运行端未读回 | 已保存，等待生效 | 已应用到在途任务 |
| 原生回读部分字段已改变 | 部分生效；展示实际值与待核实项 | 全部失败或全部成功 |
| 原请求失败，但读回实际配置符合目标 | 实际已生效，原操作失败 | 改写原回执为成功 |
| 网络/持久化/回执结果不明确 | 结果待核实；保留原编号 | 未执行、可安全重跑 |
| 授权规则允许，节点/容器未核实 | 策略允许，运行环境待核实 | 一定可执行 |
| 安装配置存在 | 已配置；服务状态单独显示 | 当前服务在线 |
| 账号/凭据来源位置存在 | 已配置来源，登录未验证 | 已成功登录 |
| 原任务已终态，证据尚未取回 | 查看结果 | 继续执行或重新执行 |
| 消息持久化、渠道确认、用户已读 | 已保存、已投递、已读（分别核实） | 任务完成或验收通过 |
| 窗口、扫描或导出只覆盖部分数据 | 当前可见范围/结果不完整 | 全局无工作、完整历史 |

## 名词与页面标签

- 一般硬件实体使用“电脑”，协议/诊断需要时保留“Agent/节点”。项目入口使用“项目”，不以历史“映射”作主标签。
- OAuth 连接、授权范围、访问令牌是不同对象，不统一混称“连接”。
- 结果、操作回执、验收和证据不是同义词：日常优先说结果，涉及未知执行、权限和恢复时保留必要精确术语。
- 服务健康、维护排空、更新器收尾、Agent 版本关系分别说明。正常非维护的 drain_ready=false 不是健康故障。
- “重试”只用于上下文明确、不会混淆新旧操作的局部读请求；对可能有副作用的动作必须使用上表具体动词。

## 验收边界

逐条核对可见文字和真实调用：只读恢复不能走新写请求；作用域变化不得复活旧确认；不同错误不能因为同一状态颜色而失去原因。禁用原因应在界面可读，不仅藏在 title。已有历史文档保留历史事实，冲突的实施指引以本词典和当前恢复协议为准。
