# 微信扫码登录与面板开关

## 入口

协作中心 → 选择房间 → 连接 → 通道与执行边界 → 管理通道与范围。

空间管理员可独立开关微信和 Telegram，设置按当前空间、当前账号所有者持久保存并立即生效。微信未配置时默认开启接入功能；Telegram 默认关闭。已有显式 CODEPIER_WEIXIN_ENABLED=false 在首次面板操作前仍保持关闭，面板明确操作后以保存值为准。协作主功能关闭时通道不能工作。普通用户与 MCP grant 不能管理开关或扫码凭据。

开启功能不会自动登录、创建机器人、绑定房间、开放权限或发送消息。关闭会停止新的收发和轮询、使在途轮询失效并清除未完成扫码；凭据、原绑定和已收消息保留。已经提交给供应商的消息无法撤回，结果不明时保留 unknown，不自动重发。重开继续原游标补收未读内容，并按原消息身份去重；关闭时隔离的发送分项不会自动补发。

## 扫码流程

1. 在微信区点击“扫码登录微信”。先阅读本服务加密保存扫码凭据的说明，并准备在手机微信授权页核对其展示的条款和使用资格。
2. 用本人手机微信扫描当前二维码，在手机中自行确认。二维码由本服务本地生成，不向第三方制码网站传送登录内容。
3. 若微信要求数字验证，在面板输入手机当前显示的数字；不要把机器人令牌或密码放进此栏。
4. 面板收到确认后，显示实际扫码身份和机器人编号。核对是否本人，再明确确认保存凭据。浏览器、审计和普通回执均不返回机器人令牌。
5. 按界面引导选定当前话题中的 dot，确认入站消息与回复范围，发送一次性 CPW 配对码并核对返回联系人。扫码成功只登记账号，不自动代替房间绑定和外发同意。

默认不显示手填编号/令牌的常规流程；“高级：登记已有授权机器人”保留兼容已有凭据。

## 中断与恢复

- 扫码有效期五分钟。取消、刷新或过期会清除待确认凭据；刷新先取消旧二维码，再明确创建新请求。
- 重复点击及丢失应答沿用原请求；一个话题同一时刻只有一个有效扫码流程。晚到的扫码结果不能覆盖已取消或切换的话题。
- 微信提示已有连接时，请核对原账号。本流程不猜测旧令牌、不静默覆盖其他房间的凭据。
- 供应商返回不同服务节点时，只接受部署原本批准的 HTTPS API 清单；不跟随任意主机或 HTTP 重定向。未受支持节点应人工核对，不以放宽安全检查解决。
- 本地二维码编码支持最多 857 个 UTF-8 字节；过长或无效的供应商内容明确失败，不使用第三方图片替代。

## 实现与验证边界

扫码协议独立实现自腾讯官方 [openclaw-weixin 固定版本协议](https://github.com/Tencent/openclaw-weixin/blob/c6643f6f0ac03574eb126f2d69569ea4267cc3c6/docs/protocol.md#qr-code-login)，包版本 2.4.10。这是 iLink 机器人私聊接入，不是公众号 OAuth 或原生群聊。

固定版本文档没有单独给出微信用户服务条款 URL，因此不把代码许可证当作用户条款；请以实际手机微信授权页展示的条款和资格要求为准。

合成供应商、事务及浏览器测试证明本地状态机，不证明真实账号资格或腾讯服务的可用性。真实扫码、实际账号持久授权、生产开关以及真实消息往返必须由账号所有者另行操作并核验。代码更新与生产配置是不同步骤。
