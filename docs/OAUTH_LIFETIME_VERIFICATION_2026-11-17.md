## 已实现

- OAuth 访问凭据与授权期限一致；无限期不返回 expires_in，新授权不再签发 refresh_token。
- 升级前仍有效的 access token 保留原值并接续同一授权期限。
- 仍有效的旧 refresh token 原地迁移为授权下的持久兑换入口；并发、重试、休眠后再兑换返回相同的稳定 access token。
- 原 grant/client/空间/权限与绝对期限保留；过期、撤销、删除或已经消费的旧凭据不复活。旧 consumed token 的迟到请求不再撤销当前连接。
- SQLite 写事务保证升级、结果创建和并发兑换原子化；稳定结果加密存储并纳入离线密钥轮换。
- 兼容代提升到 2，既有持久状态合同最低读写版本提升到 1.33.23，防止旧写入者重新轮换已迁移凭据。
- 版本文件、前端缓存版本、公开源码清单、接入说明和部署回滚说明同步更新。

## 实际旧源码跨进程升级演练

原操作：3b726e0964b04a3d82868367cb60c54a。

在私有临时目录导出基线提交，用其实际 1.33.22 源码生成合成无限期授权，确认响应包含一小时 access token 和旧 refresh token。关闭旧进程后，以相同状态目录分别运行候选版本、再次重启、离线重加密后再启动。

三个阶段均验证：
- 原 access token 可继续调用 MCP ping；
- 原 refresh token 连续三次兑换成功；
- 新响应没有 refresh_token 或 expires_in；
- 每次得到相同稳定 access token；
- grant_id 不变，重启和重加密前后的稳定结果不变。

本演练使用 FastAPI TestClient 在独立 Python 进程中运行实际源码；真实 TCP/Agent 行为由上述集成测试覆盖。临时合成凭据和状态在演练结束后删除，没有读取或迁移生产令牌。
